КАК ПОЛУЧИТЬ МОД (.jar)
=======================
Вариант 1 — на своём компьютере (Windows):
  1. Установите JDK 21: https://adoptium.net/
  2. Дважды щёлкните по build.bat
  3. Дождитесь слова ГОТОВО — откроется папка с файлом autosell-1.0.0.jar
  4. Скопируйте этот файл в папку mods (%appdata%\.minecraft\mods)

Вариант 2 — без установки Java (через GitHub):
  1. Создайте репозиторий на github.com и загрузите в него все файлы проекта
     (вместе с папкой .github)
  2. Откройте вкладку Actions -> build -> когда завершится, внизу скачайте autosell-mod
  3. Внутри будет autosell-1.0.0.jar

Для игры нужны: Minecraft 1.21.4, Fabric Loader 0.16.10+, Fabric API (в папку mods).
Клавиши: M — продать, H — поиск, I — настройки.

Встроенные функции:
  V — включить/выключить FastExp (держите бутылочку опыта в основной руке).
  Shift + колесо мыши над предметом — быстро переместить предмет между инвентарём и контейнером.
